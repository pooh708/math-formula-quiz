# 수학 공식 암기시험: 무료 수식 인식 + 무작위 12문항

## 현재 상태

* 출제·필기 화면·학생별 문항 무작위·수식 비교·결과 CSV를 구현했습니다.
* 수식 전용 인식 엔진은 **오픈소스 ink-on 0.1.0의 CoMER ONNX 모델**을 사용합니다. 이전에 사용해 보신 `ink-on.vercel.app`의 웹 유료 플랜을 신청하지 않습니다. 오픈소스 소프트웨어와 웹 서비스는 다릅니다.
* 이 압축파일에는 7.2MB 크기의 모델 파일을 포함하지 않았습니다. **배포 빌드에서 GitHub 공개 릴리스에서 자동 다운로드**하도록 만들었습니다. HTML 파일 하나를 구글 사이트에 붙이는 것만으로는 작동하지 않습니다.
* 모델의 실제 Windows 크롬 필기 정확도는 이 환경에서 아직 실행 검증하지 못했습니다. 개발자가 보고한 CROHME 2014 전체 수식 정확 일치율은 약 36.41%로, 정식 평가에 충분하다고 단정할 수 없습니다. 인식 결과를 학생이 확인하도록 설계했고 확신할 수 없는 수식은 확인 보류 가능합니다.
* 정답은 브라우저에서 처리하므로 코드에서 볼 수 있습니다. **보안시험/공식성적** 용도로 배포할 수 없습니다. 연습·형성평가에 적합합니다.

## 0원에 배포하기: GitHub Pages

1. [github.com](https://github.com/)에서 무료 계정을 만듭니다.
2. `수학공식_무료필기시험` 압축을 풉니다.
3. GitHub에서 `New repository`를 눌러 **Public** 저장소를 만듭니다. 예: `formula-quiz`.
4. `Add file` → `Upload files`에서 압축을 푼 **폴더 안의 내용 전체**를 루트에 올립니다. `.github/workflows/pages.yml` 등 숨김 폴더도 포함되어야 합니다. ZIP 자체를 업로드하면 안 됩니다. 컴퓨터에서 Git을 사용하면 폴더를 통째로 push하는 편이 더 확실합니다.
5. `Settings` → `Pages` → `Build and deployment`에서 Source를 **GitHub Actions**로 설정합니다.
6. `Actions` 탭에서 `Deploy free math quiz` 작업이 성공하면 Pages 주소를 엽니다. 생성된 주소는 `https://계정명.github.io/저장소명/` 형식입니다.
7. Google Sites에서 `삽입` → `퍼가기` → `URL`에 해당 주소를 입력하면 학생이 구글 사이트에서도 볼 수 있습니다. 구글 사이트 삽입창이 차단되면 링크로 바로 여는 방식이 더 확실합니다.

GitHub Actions를 처음 사용하는 계정은 작업 허용을 요청할 수 있습니다. 공개 저장소와 통상적인 교육용 소규모 배포는 무료 범위에서 가능하지만 GitHub 정책/제한은 변경될 수 있습니다.

### 배포 시 파일/모델을 다운로드하지 못했다면

GitHub Actions의 실패 로그에서 `Failed downloading...`을 확인합니다. `https://github.com/kimseungdae/ink-on/releases/tag/v0.1.0` 페이지에서 다음 3개를 다운로드하고 `public/models/comer/`에 올리면 빌드가 기존 파일을 사용합니다.

- encoder_int8.onnx
- decoder_int8.onnx
- vocab.json

## 로컬 실행: 개발자 또는 컴퓨터 관리자

Node.js 22+ 설치 후 프로젝트 폴더에서 다음 명령을 실행합니다.

```
npm install
node scripts/get-models.mjs
npm run dev
```

터미널에 나타난 localhost 주소로 접속합니다. 단순히 `index.html`을 더블클릭하면 인식 엔진이 불러와지지 않습니다.

## 시험 사용방법

1. 학급·번호·이름을 입력하고 시작합니다.
2. 마우스 또는 터치로 공식을 한 칸에 자유롭게 적습니다.
3. `필기 인식하기`를 누릅니다. 인식 결과를 확인합니다.
4. 틀리게 읽혔다면 `다시 쓰기`를 누릅니다. 필요하면 `인식 결과 직접 수정` 기능도 있습니다(결과에 수정 여부 표시).
5. `이 수식으로 답안 확정` 후 다음 문제로 넘어갑니다.
6. 시험 종료 시 자동 판정 정답과 확인 필요 문항 수가 나옵니다. CSV 파일을 다운로드할 수 있습니다.

**교사용 결과 수집은 아직 자동화되어 있지 않습니다.** 학생이 각자 CSV를 내려받는 방식이며, 여러 학생 결과를 자동으로 교사에게 모으는 기능은 별도 구글 앱스 스크립트와 개인정보 관리 설정이 필요합니다.

## 채점 기준

- 수학적 동치 식(예: `n(n-3)/2`, `(n-3)n/2`)은 몇 가지 다른 변수 대입에서 동일한 경우 정답으로 간주합니다.
- 문항 5의 원본 PDF 정답은 `180(n-2)/2`로 인쇄되어 있으나 수학적으로 오류입니다. 이 버전에는 올바른 `180(n-2)/n`을 사용했습니다.
- OCR이 식을 잘못 읽으면 자동 채점도 달라질 수 있으므로 교사가 확인하고 필요시 재채점해야 합니다.
- 이 앱은 검증 가능한 제한된 연산(+ - × ÷ 지수, 괄호, 분수, π 등)을 다루며 완전한 기호대수 판정기는 아닙니다.

## 데이터 보호

이 시험 앱은 학생 정보를 서버로 자동 전송하지 않습니다. 브라우저 탭에서만 응시 내용이 유지되며 새로고침하면 진행 중 데이터가 사라집니다. 학생별 CSV를 수합한다면 학교의 개인정보 보호 기준을 준수해야 합니다.
