# 수학 공식 암기시험 v7 — 학생용·교사용 분리

이 버전은 v6의 마우스/터치 자유 필기와 ink-on 수식 인식, `v→r`, `b→6`, `0→°` 보정 버튼을 유지합니다. 문제는 한 문항씩 표시되고 문항 순서는 무작위입니다.

## 주요 변경

- 다른 탭/앱으로 전환하면 화면 가림(`visibilitychange`)과 창 포커스 상실(`blur`) 이벤트를 참고 기록으로 저장합니다. 이벤트가 중복 발생할 경우 약 1.6초 안의 것은 묶어 기록합니다. 이것만으로 부정행위를 증명할 수 없습니다.
- 학생 화면과 CSV에 정답/채점 결과를 표시하지 않습니다. 학생이 보는 JavaScript의 `questions.js`는 문제 설명만 포함합니다.
- 제출 후 교사의 Google Apps Script에서만 수식 비교 채점을 수행합니다.
- 서버는 오답/판정 보류/학생 수정 답안의 필기 이미지를 기존 Google Drive 폴더에 저장합니다.
- 교사용 기존 시트 `문항별결과`, `학생별요약`을 재사용하고 `이탈횟수` 등 열을 추가합니다.
- 학생은 교사가 알려준 **시험 참여 코드**를 입력해야 제출할 수 있습니다. 이 코드는 GitHub에 저장하지 않고 Apps Script의 Script Properties에만 보관합니다.

## A. GitHub 수정

기존 저장소 https://github.com/pooh708/math-formula-quiz 에서 다음을 적용합니다.

1. `src` 폴더의 `main.js`, `questions.js`, `reporting.js`를 이 배포본의 같은 파일로 교체합니다.
2. `src/reporting.js`의 세 번째 줄 `REPORT_URL = ''`에 **기존 Apps Script `/exec` 주소**를 붙여넣습니다. 코드 안에 참여 코드를 넣지 마세요.
3. `tests` 폴더에 `public.test.mjs`를 추가하고 과거의 `grading.test.mjs` 파일을 삭제합니다.
4. 루트의 `package.json`을 새 파일로 교체하고 `README_KO.md`도 새 설명서로 교체합니다.
5. 예전 `src/grading.js`를 삭제합니다. **삭제해도 과거 Git 기록에서는 정답이 노출될 수 있습니다.** 기존 12문항은 이미 공개되었기 때문에 높은 보안을 요구하는 실제 시험에서는 새 문제은행과 새 저장소를 고려하세요.
6. `.github/workflows/pages.yml`, `public`, `scripts`, `vite.config.js`는 유지합니다.
7. Actions의 `Deploy free math quiz`가 성공했는지 확인합니다.

변경할 파일은 `github_upload`에 들어 있습니다. **`teacher_private` 폴더는 절대로 GitHub에 업로드하지 마세요.**

## B. Google Apps Script 수정

1. 기존 교사용 스프레드시트 → 확장 프로그램 → Apps Script를 엽니다.
2. `Code.gs`의 기존 내용을 모두 `TEACHER_APPS_SCRIPT_V7.gs` 내용으로 교체합니다.
3. 왼쪽 **프로젝트 설정(톱니바퀴)** → **스크립트 속성** → 속성 추가:
   - 이름 `EXAM_CODE`
   - 값: 선생님이 직접 정한 **6자 이상의 임의 코드** (학생에게 시험 시작 시 안내)
   - 이 값을 GitHub에 기록하지 마세요.
4. 상단 함수 선택에서 `setup`을 선택하고 실행합니다. 기존 시트/폴더를 재사용합니다.
5. **배포 → 배포 관리 → 기존 웹 앱 배포 수정(연필) → 버전: 새 버전 → 배포**로 갱신합니다. `새 배포`를 만들면 URL이 바뀔 수 있습니다. 실행 사용자 `나`, 액세스 권한은 학교 정책에 따라 설정합니다. `모든 사용자`는 공개 제출 경로이므로 주의가 필요합니다.
6. URL이 변하지 않았다면 GitHub의 `REPORT_URL`은 그대로 사용합니다.

## C. 시험 검증 (실제 학생 정보 사용 금지)

1. 배포된 페이지에서 `1-1 / 99 / 테스트학생`과 교사가 정한 `EXAM_CODE`를 입력합니다.
2. `n-3`은 올바르게, `n-2`는 일부러 틀리게 쓰는 등 12문항을 풀어 전송합니다.
3. 시험 도중 **한 번 다른 탭으로 이동하고 돌아옵니다.**
4. 제출 시 새 탭에 **접수 완료**가 표시되어야 합니다. 실패 메시지가 뜨면 학생 시험 화면을 닫지 마세요.
5. `학생별요약`에서 점수와 이탈 횟수를 확인합니다.
6. `문항별결과`에서 오답/보류/수정 문항의 `원본필기링크`가 생성되는지 확인합니다.
7. Drive의 `수학공식시험_오답필기_교사용` 폴더를 확인합니다.

## 주의사항

- 학생이 소스코드를 수정하거나 다른 기기에서 답을 검색하는 것을 일반 웹앱으로 막을 수 없습니다. 이탈 횟수는 참고 기록이지 부정행위 확정 근거가 아닙니다.
- 참여 코드는 약한 통제 장치입니다. 비밀번호 인증이나 부정 제출 방지 시스템으로 간주하지 마세요.
- 과거 공개 Git 기록에 기존 12문항 정답이 남아 있을 수 있습니다. 서버로 옮기는 것은 **새로운 버전의 브라우저 정답 노출**을 줄이는 조치입니다.
- 수학적 동치 비교는 여러 표본 값으로 식을 평가하는 간이 판정입니다. 엄밀한 기호 증명은 아닙니다. 학생이 OCR 결과를 수정한 문항은 이미지가 남도록 설계했습니다.
- Drive 및 시트는 비공개로 관리하고 실제 학생 데이터 수집 시 학교 개인정보 규정과 보존 기간을 따르세요.
- Google Apps Script, GitHub Actions, Drive에는 무료 사용량 한도가 있습니다. 영구적인 무제한 무료 제공을 보장하지는 않습니다.
